# Restaurant Admin Helper

Local landing page prototype for validating a restaurant admin workflow project with independent restaurants, cafes, bakeries, takeout shops, and bubble tea shops in Toronto/GTA.

The first screen is a public landing page for outreach and early feedback. The existing demo dashboard is still available at `/app` for future product exploration.

## Install

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Then open the local URL printed by Vite, usually:

```text
http://127.0.0.1:5173/
```

## Build

```bash
npm run build
```

## Current Scope

- Responsive landing page
- Founder-led local positioning
- Dashboard-style hero mockup with fake sample numbers
- Problem, workflow, positioning, pilot, contact, and footer sections
- Static feedback form with a demo alert on submit
- No backend or paid libraries

## Future Form Options

The feedback form is structured so it can later connect to Formspree, Google Forms, Supabase, or a custom API endpoint.
